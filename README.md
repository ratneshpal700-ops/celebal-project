# Machine Learning & Deep Learning Assignments

A collection of end-to-end machine learning, deep learning, and generative AI assignments covering Python fundamentals, data analysis, predictive modeling, computer vision, natural language processing, and LLM-based AI applications.

---

## 📂 Contents

| # | Assignment | Topic | Key Techniques |
|---|------------|-------|-----------------|
| 1 | `ASSIGNMENT_1.ipynb` | Python & Data Manipulation Fundamentals | Functions, control flow, exception handling, NumPy arrays, matrix operations, Pandas data manipulation, filtering, grouping, handling missing values |
| 2 | `Assignment_2.ipynb` | Tesla Deliveries — Regression Analysis | Exploratory Data Analysis (EDA), correlation heatmaps, feature engineering, one-hot encoding, Random Forest Regressor, MAE, RMSE, R² Score, future prediction |

---

## 🧠 Overview

- **Assignments 1–3** build a strong foundation in Python programming, data manipulation with NumPy and Pandas, exploratory data analysis, regression modeling, and unsupervised machine learning.
- **Assignments 4–6** focus on deep learning using TensorFlow/Keras, covering image classification with CNNs, sequence modeling using RNN/LSTM/GRU, and denoising autoencoders for representation learning.
- **Assignment 7** demonstrates a Retrieval-Augmented Generation (RAG) system that combines semantic search with Large Language Models for document-based question answering.
- **Assignment 8** showcases a Smart Query Routing AI Agent capable of understanding user intent and dynamically routing requests to specialized tools including sentiment analysis, keyword extraction, translation, summarization, and mathematical computation through a modular LLM-powered architecture.
